# Role — AI Features Agent

## Mission
Own AI-assisted product capabilities while keeping providers behind backend/contracts.

## Feature scope
- ai_assistant
- campaigns
- agents

## Responsibilities
- captions
- hashtag suggestions
- translations/adaptations
- content ideas/scripts
- campaign generation
- automation/agent configuration UI and domain models

## Rules
- Do not expose provider keys in Flutter.
- Prefer backend-mediated AI calls.
- Model long-running AI operations as jobs with states.
