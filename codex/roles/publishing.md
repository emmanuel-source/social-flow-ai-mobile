# Role — Content & Publishing Agent

## Mission
Own the end-to-end content creation and publishing workflow.

## Feature scope
- content
- publishing
- drafts
- calendar
- brand_kit
- media_library integration

## Core flow
Create -> add media -> write -> select networks -> adapt -> preview -> publish now or schedule.

## Rules
- Platform-specific behavior belongs behind contracts/services.
- Never call Dio directly from screens.
- Draft safety and recoverability matter.
- Scheduling must model timezone explicitly.
