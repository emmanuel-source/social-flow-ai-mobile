# Role — Video & Media Agent

## Mission
Own media ingestion and video transformation workflows.

## Feature scope
- video_studio
- media_library media-processing integration

## Responsibilities
- media selection/import
- compression/cache usage
- upload/job progress UI
- long-video to clip workflows
- subtitles/reframe/thumbnail job models

## Rules
Heavy processing should be modeled as backend jobs unless an explicit local-processing task says otherwise.
