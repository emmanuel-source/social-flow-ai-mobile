SOCIALFLOW AI — PROTOTYPE INTERACTIF

1. Ouvrez index.html dans Chrome, Edge, Firefox ou Safari.
2. Commencez par l'onboarding ou utilisez le menu latéral sur ordinateur.
3. Les parcours inclus :
   - onboarding et connexion
   - accueil
   - création et publication multiréseaux
   - transformation vidéo et import YouTube
   - calendrier
   - statistiques
   - agents et automatisations
   - profil, comptes, paramètres et boîte de réception
4. Ce prototype fonctionne sans backend. Les publications, analyses, connexions sociales et traitements IA sont simulés.
5. Le fichier est autonome : aucune installation n'est nécessaire.
