# Definition of Done

A Social Flow AI task is done when all applicable items are true.

## Product
- Acceptance criteria satisfied.
- No known blocker left hidden in the PR.

## Code
- Architecture rules respected.
- No unnecessary package added.
- No secrets committed.
- No unrelated refactor bundled in.

## UX
- Uses design system.
- Loading/error/empty states handled where applicable.
- Basic accessibility and safe-area behavior considered.

## Quality
- Formatted.
- `flutter analyze` passes.
- Relevant tests pass.
- New business logic/regression has tests when practical.

## Collaboration
- Branch is task-specific.
- PR explains change and validation.
- Required review/CI completed before merge.
