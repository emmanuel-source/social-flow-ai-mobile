# First Day Checklist

## Owner
- [ ] Install Git
- [ ] Install Flutter stable and verify `flutter doctor`
- [ ] Install VS Code
- [ ] Install Flutter + Dart extensions
- [ ] Install the official OpenAI Codex extension / sign in
- [ ] Create the GitHub repository
- [ ] Push this starter to `main`
- [ ] Invite collaborator with appropriate access
- [ ] Configure `CODEOWNERS` usernames
- [ ] Protect `main`
- [ ] Create Sprint 1 issues

## Collaborator
- [ ] Install Git/Flutter/VS Code
- [ ] Clone repository
- [ ] Run `flutter doctor`
- [ ] Run `flutter pub get`
- [ ] Run `flutter analyze`
- [ ] Run `flutter test`
- [ ] Read `AGENTS.md`
- [ ] Read collaboration guide
- [ ] Start only from an assigned SFA task branch

## Team rule
No feature development begins until both machines can clone the same repository and pass the baseline checks.
