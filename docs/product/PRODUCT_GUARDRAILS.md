# Product Guardrails

## Core promise
Help users create, adapt, schedule, publish and analyze social content across multiple networks from one product.

## Main navigation
Exactly five top-level destinations:
- Home
- Create
- Calendar
- Analytics
- Profile

## Foundation concepts
- User
- Workspace (personal, brand, company, agency/client context)
- Social account
- Media asset
- Content/draft
- Publication
- Schedule/calendar item
- Campaign
- Analytics metric
- AI job/automation

## Planned platform model
The client model may represent Instagram, Facebook, TikTok, YouTube, Snapchat, X, LinkedIn, Pinterest and Threads. Actual API capabilities must be determined by backend/provider support, not assumed by the Flutter UI.
